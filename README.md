# Couples Finance

A browser-based walkthrough of the exercises in Ramit Sethi's *Money for Couples*. Partners answer each section in turn on a shared device, then compare their results. All data is stored in the browser's localStorage.

Built with Svelte 5, TypeScript and Vite.

## Development

```sh
npm install
npm run dev      # start dev server
npm run check    # type-check (svelte-check + tsc)
npm run build    # production build to dist/
npm run preview  # serve the production build
```
